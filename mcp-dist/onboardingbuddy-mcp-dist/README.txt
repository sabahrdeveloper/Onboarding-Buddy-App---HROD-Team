OnboardingBuddy - Claude Desktop connector
============================================

INSTALL
1. Make sure Claude Desktop is fully closed (right-click its icon in the
   system tray, bottom-right of the screen, and choose Quit/Exit).
2. Double-click SETUP.bat
   (If Windows shows a blue "Windows protected your PC" warning, click
   "More info", then "Run anyway".)
3. Wait for it to say DONE (it installs Node.js automatically if this PC
   doesn't have it - first run may take a minute).
4. Press any key to close the window.
5. Reopen Claude Desktop.
6. Ask Claude: "Give me today's help ticket report"

WHAT IT CHANGES
Adds one connector ("onboardingbuddy") to your Claude Desktop config.
Any connectors you already had stay untouched (a backup is saved next to
the config file too).
