# Review Checklist

Before finalizing PeopleDesk work, check:

- Primary Green `#2CA24D` is used correctly
- Manrope or approved fallback is used
- Page background is `#F5F6F8`
- Cards are white
- Spacing follows the 8px system
- Cards, buttons, inputs, chips, and modals use correct radius
- No gradients, glassmorphism, neumorphism, or floating action buttons
- Mobile layout has maximum two columns
- Language is Bangla-first where appropriate
- AI assistance is helpful but not dominant
- Touch targets are at least 48px x 48px
- Status colors and labels are both used
- The screen feels like PeopleDesk, not a generic app
