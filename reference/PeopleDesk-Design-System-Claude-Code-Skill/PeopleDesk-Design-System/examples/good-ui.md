# Good PeopleDesk UI

A good PeopleDesk UI:

- Uses Primary Green only for important actions and progress
- Uses white cards on light gray background
- Uses Bangla-first employee guidance
- Uses short, supportive AI messages
- Uses 8px spacing
- Uses 14px minimum body text
- Uses clear status labels
- Keeps mobile layouts to one or two columns
- Makes HR tasks feel simple and guided
