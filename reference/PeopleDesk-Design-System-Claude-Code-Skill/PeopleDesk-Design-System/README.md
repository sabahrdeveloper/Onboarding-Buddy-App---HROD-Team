## How to Use in Claude Code

Copy the `PeopleDesk-Design-System` folder into your Claude skills directory.

Common location:

```bash
~/.claude/skills/PeopleDesk-Design-System
```

Then ask Claude Code to create or review PeopleDesk screens, components, HTML/CSS, React, React Native, or Flutter implementations.
