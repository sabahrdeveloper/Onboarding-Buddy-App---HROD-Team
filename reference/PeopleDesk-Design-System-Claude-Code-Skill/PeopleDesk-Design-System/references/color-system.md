# Color System

## Primary Colors

- Primary Green: `#2CA24D`
- Primary Dark: `#0C7A35`
- Primary Light: `#EAF7ED`

## Background Colors

- Page Background: `#F5F6F8`
- Card Background: `#FFFFFF`
- Border: `#E6E8EB`

## Text Colors

- Text Primary: `#1F2937`
- Text Secondary: `#6B7280`

## Semantic Colors

- Success: `#2BA84A`
- Warning: `#E9A93B`
- Error: `#E5484D`
- Info: `#3B82F6`

## Status Colors

- Pending: background `#FFF4DD`, text `#D48806`
- Approved: background `#EAF8EE`, text `#1B8F4D`
- Completed: background `#EEF5FF`, text `#2563EB`
- Rejected: background `#FDECEC`, text `#DC2626`

## Rules

- Do not introduce unapproved colors.
- Do not use gradients by default.
- Use Primary Green for main actions, progress, and primary highlights.
- Use semantic colors only for their correct meaning.
