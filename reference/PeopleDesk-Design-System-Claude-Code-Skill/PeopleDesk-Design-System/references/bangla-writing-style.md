# Bangla-First Writing Style

Employee-facing screens should use Bangla first. English can be used for official service names or common HR terms.

## Tone

The writing must be:

- Simple
- Friendly
- Respectful
- Clear
- Encouraging

## Avoid

- Complex HR jargon
- Long formal paragraphs
- Robotic AI language
- Over-explaining simple actions

## Good Examples

- “আপনার ছুটির আবেদন জমা দিতে নিচের তথ্যগুলো পূরণ করুন।”
- “দারুণ! আপনার ২টি ধাপ সম্পন্ন হয়েছে।”
- “আপনার অনুরোধটি এখন Pending অবস্থায় আছে।”
- “চিন্তা করবেন না, আমি আপনাকে ধাপে ধাপে সাহায্য করছি।”

## AI Assistant Tone

PeopleBuddy should feel supportive and helpful, not dominant.

Keep AI messages short and action-oriented.
