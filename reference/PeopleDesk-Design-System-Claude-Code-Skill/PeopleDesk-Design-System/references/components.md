# Core Components

Reuse these components before inventing new ones.

## App Bar

Use for top-level navigation and screen identity.

Include:

- Back icon when needed
- Short screen title
- Optional simple action icon

## Progress Bar

Use for multi-step services.

Rules:

- Use Primary Green for progress.
- Keep labels short.
- Show completion clearly.

## Service Card

Use for HR service entry points.

Each card should include:

- Outlined icon
- Service title
- Optional short description
- White background
- 18px card radius
- Soft shadow

## AI Assistant Card

Use when guidance or encouragement helps.

The assistant should:

- Explain next steps simply
- Reduce confusion
- Offer smart suggestions
- Encourage gently
- Avoid long robotic explanations

Example Bangla copy:

- “ভালো হচ্ছে! এবার আপনার Movement-এর সময়টি নির্বাচন করুন।”
- “আপনার তথ্য প্রায় সম্পন্ন। আর মাত্র একটি ধাপ বাকি।”
- “চিন্তা করবেন না, আমি আপনাকে ধাপে ধাপে সাহায্য করছি।”

## Status Badge

Use approved status colors only.

Statuses:

- Pending
- Approved
- Completed
- Rejected

## Request List Item

Use for recent requests and service history.

Include:

- Request type
- Date or time
- Status badge
- Short supporting detail

## Modal Dialog

Use for confirmations, success messages, warnings, and important decisions.

Rules:

- Modal radius: 28px
- Primary CTA uses Primary Green
- Use supportive, clear language

## Smart Suggestion Chips

Use to guide likely next actions.

Examples:

- Apply Movement
- Check Leave Balance
- Download Pay Slip
- View Pending Requests
