# HR Service Flows

## Movement Request Flow

Use this flow for Movement Request screens.

### Step 1: AI Guidance

Show an AI Assistant Card explaining what the employee needs.

Example:

“PeopleDesk-এ Movement আবেদন করতে হলে আপনার Movement Date, Time, Destination এবং Purpose দিতে হবে। আমি আপনাকে ধাপে ধাপে সাহায্য করবো।”

### Step 2: Form Completion

Use underline inputs and simple form sections.

Common fields:

- Employee Enroll Number
- Movement Date
- Movement Time
- Destination
- Movement Purpose
- Reporting Manager
- Attachment, if required

Rules:

- Use underline inputs.
- Keep labels clear.
- Use friendly helper text.
- Show progress using a green progress bar.
- Avoid long forms on one screen when a step-by-step flow is better.

### Step 3: Success Modal

Success message example:

“আপনার Movement Request সফলভাবে জমা হয়েছে। Approval-এর জন্য এটি আপনার Reporting Manager-এর কাছে পাঠানো হয়েছে।”

CTA examples:

- View Request
- Back to Dashboard
