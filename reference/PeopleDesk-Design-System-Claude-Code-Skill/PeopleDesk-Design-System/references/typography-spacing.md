# Typography and Spacing

## Typography

Primary font:

- Manrope

Fallback:

- Inter
- Roboto
- System sans-serif

Type scale:

- Screen Title: `20px`, weight `700`
- Section Header: `18px`, weight `700`
- Card Title: `16px`, weight `600`
- Body: `14px`, weight `400`
- Small: `12px`, weight `500`

Rules:

- Minimum body text size: `14px`
- Body line height: 150%
- Keep headings short and practical.
- Avoid long formal copy in mobile screens.

## Spacing

Use the 8px spacing system.

Allowed spacing values:

- `4px`
- `8px`
- `12px`
- `16px`
- `20px`
- `24px`
- `32px`
- `40px`
- `48px`

Default mobile horizontal padding:

- `16px`

## Border Radius

- Chips: `16px`
- Buttons: `14px`
- Cards: `18px`
- Modals: `28px`
- Inputs: `14px`

## Shadows

- Cards: `0 2px 8px rgba(0,0,0,.06)`
- Floating: `0 8px 24px rgba(0,0,0,.12)`
- Modal: `0 24px 64px rgba(0,0,0,.20)`
