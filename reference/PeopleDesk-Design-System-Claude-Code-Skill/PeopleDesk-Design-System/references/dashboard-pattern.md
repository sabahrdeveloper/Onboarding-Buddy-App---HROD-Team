# Dashboard Pattern

PeopleDesk dashboard screens should follow this order:

1. Welcome Section
2. Task Progress
3. PeopleBuddy Card
4. HR Services Grid
5. Smart Suggestions
6. Recent Requests
7. Badges

## Dashboard Rules

- Start with a warm, employee-friendly welcome.
- Show task progress early.
- Place PeopleBuddy or AI assistance near the top.
- Use service cards in a simple grid.
- Do not use more than two columns on mobile.
- Keep recent requests visible but not dominant.
- Badges should encourage employees without feeling childish.
