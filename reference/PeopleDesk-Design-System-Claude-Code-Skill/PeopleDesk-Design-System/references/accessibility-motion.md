# Accessibility and Motion

## Accessibility

Always follow:

- Minimum touch target: `48px x 48px`
- WCAG AA contrast
- Minimum body text: `14px`
- Body line height: 150%
- Clear error messages
- Large enough tappable buttons
- Do not use color-only status communication; include status labels too

## Motion

Use subtle motion only.

Allowed motion:

- Page transition: 250ms
- Modal animation: Scale + Fade, 300ms
- Button press scale: 0.97

Avoid:

- Excessive animation
- Distracting transitions
- Childish gamification
- Motion that slows task completion
